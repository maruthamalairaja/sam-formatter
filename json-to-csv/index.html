Frequently Asked Questions

Everything you need to know about converting JSON to CSV.

Is my JSON data uploaded to any server?

No. SAM Data Formatter operates 100% inside your web browser using JavaScript. No network requests are made with your data.

Can this tool handle nested JSON objects?

Yes. Nested objects and arrays are intelligently inspected and serialized into clean column representations.

Can I open the resulting CSV in Microsoft Excel or Google Sheets?

Yes. The output is formatted according to standard CSV specifications and opens seamlessly in Excel, Google Sheets, LibreOffice, and SQL databases.

Is there a limit on how much JSON I can convert?

There are no artificial limits. Because it runs locally on your computer, you can process thousands of records in seconds.
